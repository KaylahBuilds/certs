## Suggested sequence

1. Read blueprint and understand weight distribution.
2. Use this local repo labs to build fundamentals quickly.
3. Pull one advanced workflow from `NVIDIA/GenerativeAIExamples`.
4. Study deployment and retrieval docs from NIM + NeMo Retriever docs.
5. Re-run your weak labs before each mock test.
