# CAPA Priority Bootcamp (6 Days)

## Goal

Demonstrate practical fluency across the Argo ecosystem: Argo CD, Argo Rollouts, Argo Workflows, and Argo Events.

## Day Plan

1. Day 1: Argo ecosystem architecture
- Understand control loops, CRDs, and event-driven automation.
- Map ownership boundaries between CD, rollout, workflow, and event systems.

2. Day 2: Argo CD fundamentals
- Model an Application and sync policy.
- Practice drift detection and self-heal behaviors.

3. Day 3: Argo Rollouts progressive delivery
- Build a canary rollout with weighted traffic steps and pause gates.
- Validate promotion and rollback behavior.

4. Day 4: Argo Workflows orchestration
- Build reusable WorkflowTemplate and submit execution flows.
- Capture execution evidence and failure handling.

5. Day 5: Argo Events automation
- Configure webhook EventSource + Sensor trigger.
- Validate event-to-workflow automation path.

6. Day 6: Timed full-stack run
- Deploy from clean environment.
- Trigger event-driven rollout check and capture evidence.

## Pass Criteria

- Explain each Argo component in one sentence and one diagram.
- Perform a controlled canary promotion and rollback.
- Show end-to-end event-driven workflow trigger.
