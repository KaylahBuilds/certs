# CNPE Priority Bootcamp (8 Days)

## Goal

Build and operate a platform engineering capstone that demonstrates secure self-service, GitOps delivery, policy enforcement, and operational observability.

## Day Plan

1. Day 1: Capstone architecture and scope
- Define platform boundaries, tenancy model, and service lifecycle.

2. Day 2: Platform API contract
- Create a namespaced platform API for service onboarding requests.

3. Day 3: Multi-tenant access model
- Build RBAC controls and namespace ownership boundaries.

4. Day 4: GitOps delivery pipeline
- Define Argo CD project and application model for tenant rollout.

5. Day 5: Policy enforcement in enforce mode
- Implement policy checks for labels and image trust.

6. Day 6: Observability baseline
- Deploy OpenTelemetry collector path and collect platform signals.

7. Day 7: Failure simulation and incident runbook
- Simulate policy, deployment, and rollout failures.
- Build recovery paths and operational checklists.

8. Day 8: Timed capstone execution
- Rebuild from a clean environment with full evidence capture.

## Pass Criteria

- End-to-end platform narrative that is reproducible.
- Clear separation of API, policy, delivery, and observability concerns.
- Strong failure-handling evidence with recovery speed metrics.
