# CNPE Capstone Checklist

## Platform Contract

- [ ] Platform API CRD and sample claim defined
- [ ] Ownership and metadata requirements explicit

## Delivery

- [ ] Argo CD project and application declarations created
- [ ] Promotion and rollback path documented

## Security

- [ ] Namespace and RBAC boundaries implemented
- [ ] Policy controls active in enforce mode where safe

## Observability

- [ ] Collector and telemetry path deployed
- [ ] Core service health and platform events observable

## Operations

- [ ] Incident scenarios rehearsed
- [ ] Runbook includes diagnosis, mitigation, and rollback steps
