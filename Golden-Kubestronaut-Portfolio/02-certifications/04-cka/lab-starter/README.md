# CKA Lab Starter

## Scenario

Provision and operate a production-style Kubernetes cluster

## Goal

Install, configure, and operate core cluster services with repeatable procedures.

## Build Plan

1. Document architecture assumptions in notes/commands.md.
2. Create manifests and configs in manifests/cluster-ops/.
3. Add helper automation in scripts/setup.sh and scripts/validate.sh.
4. Execute one failure scenario and one recovery scenario.

- [ ] Failure and recovery evidence captured
