# CNPA Lab: Platform Engineering Associate Scenario

## Scenario

You are defining a minimum viable internal developer platform for two product teams. The platform must provide self-service onboarding, deployment guardrails, and measurable outcomes.

## Lab Outcomes

- Platform namespace and team tenancy model
- Backstage catalog entities and scaffolder template
- GitOps app project and app declaration
- Policy guardrails for safe defaults
- KPI baseline and target scorecard

## Build Sequence

1. Apply platform and tenant namespaces.
2. Apply catalog and template artifacts.
3. Apply GitOps app project and sample app definitions.
4. Apply guardrail policies.
5. Publish KPI scorecard and platform metrics assumptions.

## Validation Sequence

- Run scripts/validate.sh
- Verify dry-run linting and policy object presence
- Record KPI assumptions and evidence links in notes/platform-kpis.md
