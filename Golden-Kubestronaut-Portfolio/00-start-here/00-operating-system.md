# Operating System For This Journey

## Weekly Cadence

- Monday to Friday: 90 minutes study + 60 minutes hands-on lab
- Saturday: 3-hour timed practice block
- Sunday: review notes, flashcards, and weak areas

## Per-Certification Workflow

1. Read exam domains and build a short gap list.
2. Draw or update architecture diagram for the cert.
3. Build the hands-on lab in the cert folder.
4. Capture evidence using the shared templates.
5. Run one timed mini-mock before scheduling exam.

## Definition Of Done (Per Certification)

A certification is "done" in this repo when:

- architecture diagram is complete
- infographic snapshot is complete
- lab is complete and reproducible
- evidence templates are filled out
- exam attempt notes are committed

## Branching And Commit Style

- Branch per certification: `cert/<code>-prep`
- Branch per lab: `lab/<code>-<lab-name>`
- Commit format: `<code>: <artifact> - <summary>`

Examples:

- `CKA: lab manifests - add HA control plane exercise`
- `OTCA: evidence - add trace analysis write-up`
