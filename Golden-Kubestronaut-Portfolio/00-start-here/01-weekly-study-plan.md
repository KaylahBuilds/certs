# 90-Day Study Plan

This is a 90-day execution plan for completing all 16 required certifications.

If Day 1 is **May 11, 2026**, Day 90 lands on **August 8, 2026**.

## Daily Cadence

- Block A (90 min): domain review and notes
- Block B (90 min): timed drills and commands
- Block C (120 min): hands-on lab build and evidence capture

Target: 5-6 focused hours per day.

## Weekly Cadence

- Monday to Friday: build and drill
- Saturday: two timed mock blocks
- Sunday: weak-area repair and repo cleanup

## 90-Day Phase Windows

- Days 1-21: Foundations (LFCS, KCNA, KCSA)
- Days 22-51: Core Kubernetes (CKA, CKAD, CKS)
- Days 52-79: Specialties (PCA, OTCA, CCA, ICA, CGOA, CAPA, KCA)
- Days 79-90: Platform engineering finish (CBA, CNPA, CNPE)

## Publish Rhythm (For GitHub Signal)

- Daily: one progress commit
- Every 3 days: one lab evidence commit
- Weekly: one retrospective commit with blockers and fixes
