# Lab 01: Architecture Mapping Drill

## Goal

Build a clear mental model of AI infrastructure layers and operational responsibilities.

## Tasks

1. Open `../../diagrams/nca-aiio-architecture-diagrams.md`.
2. Redraw Diagram 1 from memory.
3. For each layer, list:
   - one key component
   - one failure signal
   - one monitoring source
4. Explain training vs inference infra differences in under 90 seconds.

## Success criteria

- You can redraw the stack correctly without notes.
- You can map each failure signal to a monitoring action.
- You can explain tradeoffs in plain, exam-ready language.
