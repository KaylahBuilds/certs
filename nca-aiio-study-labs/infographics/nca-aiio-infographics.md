## 2) Fast Recall: GPU Operations Signals

| Signal | Why it matters | Typical risk |
|---|---|---|
| GPU utilization | Capacity and packing efficiency | Underutilization or saturation |
| Memory utilization | Workload fit and headroom | OOM failures, retries |
| Temperature/power | Thermal and power stability | Throttling, instability |
| Error events (XID/RAS) | Reliability and hardware health | Node degradation, job failures |
| Interconnect health | Multi-GPU communication | Throughput collapse |

## 3) Incident Severity Grid

| Severity | Condition | Action |
|---|---|---|
| Sev-1 | Broad outage or severe SLA breach | Immediate escalation, mitigation first |
| Sev-2 | Partial degradation | Prioritized fix with close monitoring |
| Sev-3 | Minor issue or early warning | Planned remediation |

## 4) On-Prem vs Cloud Tradeoff Card

| Topic | On-Prem | Cloud |
|---|---|---|
| Control | High control over stack | Managed abstractions |
| Scaling speed | Slower procurement cycles | Fast elastic provisioning |
| Cost profile | High upfront capex | Usage-based opex |
| Ops burden | Higher internal burden | Shared provider responsibility |
